## 6. Qué pasa si falta un archivo

- Intro: se muestra placeholder premium o texto fallback
- Preguntas: se muestra vaso placeholder estilizado
- Resultado: se muestra una bebida placeholder
- Beneficio: se usa el icono de regalo del sistema
