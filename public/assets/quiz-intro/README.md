# Assets portada quiz

Deja aqui los assets finales de la portada del quiz.

## Estructura recomendada

```text
public/assets/quiz-intro/
  logo/
    dunkin-logo.svg
  drinks/
    iced-latte.png
    Refresher-Mango-Piña.png
    frutibatido.png
    frozen-original.png
  reference/
    mockup.png
```

## Notas

- Usa PNG con fondo transparente para las bebidas.
- Usa SVG para el logo si es posible.
- Si aun no estan los archivos, la interfaz usa placeholders visuales.
- Toma `manifest.example.json` como guia para nombres y rutas.
