# Contribución al Proyecto

## ¿Quién puede contribuir?

Solo el personal autorizado por Dunkin Colombia puede contribuir a este proyecto.

## Proceso de Contribución

1. Crea una rama nueva desde `main`
2. Realiza tus cambios
3. Asegúrate de que el código pase todas las pruebas y linters
4. Crea un Pull Request (PR)
5. Espera la revisión de al menos un miembro del equipo autorizado
6. Tu PR será fusionado una vez aprobado

## Buenas Prácticas

- Hacer commits pequeños y descriptivos
- Actualizar la documentación cuando sea necesario
- Seguir las guías de estilo establecidas en el proyecto
- No incluir credenciales o datos sensibles en el código
- Testear tus cambios antes de enviar un PR

## Comunicación

Toda comunicación sobre el proyecto debe ser profesional y respetuosa.
